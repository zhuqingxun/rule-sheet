# rule-sheet 使用指南

本文讲怎么用: 安装运行、规则文件的两种写法 (Excel 决策表 / YAML) 的精确格式、单元格与表达式语法、输出结果、Python API 和常见报错。为什么这样设计见 [设计架构.md](设计架构.md)。

## 1. 安装与命令

需要 [uv](https://docs.astral.sh/uv/)。在项目目录执行:

```powershell
uv sync
uv run rule-sheet run  examples/customer-sync/规则_决策表.xlsx   # Excel 决策表
uv run rule-sheet run  examples/customer-sync/rules.yaml         # 同一组规则的 YAML 版
uv run rule-sheet test examples/customer-sync/rules.yaml         # 只跑规则文件内嵌的测试用例
uv run rule-sheet --version
```

`rule-sheet <规则文件>` 省略子命令等价于 `run`。

| 子命令 / 选项 | 作用 |
|---|---|
| `run <规则文件>` | 先跑内嵌测试, 全部通过才读两表、执行规则、写出结果 |
| `run --output PATH` | 覆盖规则文件里的输出路径 |
| `run --base-dir DIR` | 规则文件内相对路径 (左表 / 右表 / 输出) 的基准目录, 默认规则文件所在目录 |
| `run --ignore-tests` | 内嵌测试有失败也继续处理真实数据 |
| `run --dry-run` | 只打印变更, 不写文件 |
| `test <规则文件>` | 只跑内嵌测试用例, 不读数据表 |

退出码: `0` 成功; `1` 测试未通过 (`run` 因此停止, 或 `test` 有失败); `2` 规则文件 / 数据有错 (打印 `错误: ...`)。

## 2. 任务目录约定

一个任务一个文件夹, 两份数据和规则文件放一起, 规则文件里用相对路径引用数据:

```
customer-sync/
  客户主表.xlsx        左表, 被更新的表
  本月流水.xlsx        右表, 参照表, 只读
  规则_决策表.xlsx     规则 (Excel 写法)
  rules.yaml           规则 (YAML 写法, 可选)
  output/              结果输出 (不进 git)
```

## 3. 规则文件: Excel 决策表写法

一个 `.xlsx`, 四张 sheet。sheet 名固定; `匹配设置` 与 `决策表` 必须有, `变量定义` 与 `测试` 可选。

### 3.1 匹配设置

第 1 行表头 (任意文字), 之后每行一项: A 列设置项、B 列值, C 列说明不参与解析。

| 设置项 | 必填 | 值 |
|---|---|---|
| 左表 | 是 | 被更新的表的路径, 相对规则文件所在目录 |
| 右表 | 是 | 参照表路径 |
| 匹配键 | 是 | 两表按此列对行; 多列用逗号分隔, 如 `客户编号, 年月` |
| 左表别名 | 否 | 规则里引用左表字段的前缀, 默认 `主表` |
| 右表别名 | 否 | 引用右表字段的前缀, 默认 `本月` |
| 右表重复键 | 否 | 一对多时的处理: `取第一条` (默认) ; 填其他任何值则遇到重复键报错 |
| 基准日期 | 否 | `天数差` 等计算用的「今天」; 不填取运行当天。固定下来可保证每次结果一致 |
| 输出 | 否 | 结果文件路径, 默认 `output/结果.xlsx` |

### 3.2 变量定义 (可选)

第 1 行表头, 之后每行: A 列变量名、B 列表达式。A 或 B 为空的行忽略 (可以用来写备注)。按行顺序求值, 后面的可以引用前面的。

```
偏差率          abs(本月.金额 - 主表.金额) / 主表.金额
距上次活跃天数  天数差(基准日期, 主表.上次活跃)
```

表达式语法见第 5 节。

### 3.3 决策表

三行表头, 第 4 行起每行一条规则:

| 行 | 内容 |
|---|---|
| 第 1 行 | A1 写 `命中策略`, **B1 写策略名**: `优先级` (默认) / `唯一` / `首次命中`, 写别的报错。其余格可写说明 |
| 第 2 行 | 每列的类型: `规则ID` (必须有一列) / `优先级` (可选) / `输入` / `输出` / `说明` (可选) |
| 第 3 行 | 每列的名字: 输入列填变量名 (如 `主表.状态`、`偏差率`), 输出列填左表要写回的列名 (如 `状态`) |
| 第 4 行起 | 规则正文。`规则ID` 为空的行跳过; `优先级` 留空取 `1000 + 行序` (即排在所有写了优先级的规则之后, 按行序) |

输入格写单元格条件 (第 4 节), 输出格写要写回的值 (第 4.2 节)。同一行的各输入格之间是 AND; 不同行之间是 OR。

以 `=` 开头的格 (`= 活跃`、`= 本期.类别-会议`、`=主表.金额 * 1.1`) 在 Excel 里输入时会被当成公式, 显示 `#NAME?`。rule-sheet 读的是格里的原文, 所以照样能用; 想让它显示正常, 先把单元格设成文本格式再输入, 或以 `'` 开头。规则工作簿里不要写真正的 Excel 公式, 读到的会是公式原文而不是计算结果。

### 3.4 测试 (可选)

与决策表同样的三行表头, 第 2 行类型为 `用例` / `输入` / `期望` / `说明`, 第 3 行: 输入列填变量名, 期望列填输出列名。第 4 行起每行一个用例, `用例` 为空的行跳过。

- 输入格直接写变量的值 (不是条件)。`<右表别名>.存在` 这一列写 `是` / `否`。留空 = 该变量为空值。
- 决策表引用了、但用例没有这一列的变量, 一律视为空值。
- 期望格留空 = **该列不变**。有值 = 执行后该列应等于此值。写 `清空` (或 `为空`) = 执行后该列应为空值, 用来验证 `清空` 输出; 留空和 `清空` 不一样, 前者抓「不该动的被动了」, 后者抓「该清的没清」。
- 派生变量 (变量定义里的) 可以直接在输入里给值, 给了就不再推导; 没给则按表达式推导, 推导失败置空。

### 3.5 一张决策表长什么样

以自带样例为例 (颜色只是视觉提示, 解释器不读颜色):

| 规则ID | 优先级 | 主表.状态 | 偏差率 | 本月.存在 | 距上次活跃天数 | 本月.电话 | 状态 | 电话 | 复核标记 | 备注 |
|---|---|---|---|---|---|---|---|---|---|---|
| R1 | 1 | 活跃 | > 0.05 | 是 | - | - | - | - | 待复核 | 金额偏差超 5% |
| R2 | 2 | != 休眠 | - | 否 | > 180 | - | 休眠 | - | - | 连续 6 个月无流水 |
| R3 | 3 | - | - | 是 | - | != 主表.电话 | - | 本月.电话 | - | 电话变更 |

## 4. 单元格语法

### 4.1 输入格 (条件)

| 写法 | 含义 |
|---|---|
| `-` 或留空 (也认 `—`、`任意`) | 不关心 |
| `活跃` | 等于。裸文字按文本比较; Excel 里设成数字 / 日期格式的格按数字 / 日期比较 |
| `"VIP 小幅偏差, 关注"` | 值本身含逗号时加引号 (单双引号都可), 否则会被当成枚举拆开 |
| `> 0.05` `>= 180` `< 1` `<= 1` | 比较 |
| `= 活跃` `== 活跃` | 等于 (显式写法) |
| `!= 休眠` `<> 休眠` | 不等于 |
| `!= 主表.电话` | 比较的右侧可以是另一个变量名 |
| `[0.02..0.05]` | 闭区间; `(` `)` 为开区间, 可混用如 `(0..1]` |
| `VIP, 金卡` | 枚举: 逗号分隔, 任一满足。每一项都可以是上面任何写法, 如 `> 10, 为空` |
| `非空` / `为空` | 判空 |
| `not(...)` | 取反。只对有值的格成立, 例外: `not(为空)` / `not(非空)` 是纯否定 |
| `是` / `否` | 仅当被比较的列是布尔列 (如 `本月.存在`) 时转成真 / 假 (也认 `true` / `false` / `yes` / `no`); 文本列里就是文字 |
| `2026-10-19` | 日期字面量 |

**空值规则**: 空值参与任何比较 (等于、不等、大小、区间、枚举) 都不成立。要判空必须显式写 `为空` / `非空`。

### 4.2 输出格

| 写法 | 含义 |
|---|---|
| `-` 或留空 | 不改 |
| `待复核` | 写入这个字面值 (Excel 里的数字 / 日期格原样写入) |
| `"本月.电话"` | 加引号表示强制当文字, 即使它长得像变量名 |
| `本月.电话` | 恰好是一个变量名时, 复制该变量的值 |
| `=主表.金额 * 1.1` | 以 `=` 开头是表达式, 按第 5 节求值 |
| `清空` (也认 `置空`) | 把该列写成空值。和 `-` 不同: `-` 是不碰这一列, `清空` 是主动清掉 (变更明细显示 `旧值 -> 空`)。要写文字「清空」就加引号 |

## 5. 表达式语法 (变量定义、`=` 输出格、YAML 条件)

表达式是 Python 语义, 对整列向量化求值。可以写:

- 变量: `主表.<列名>`、`本月.<列名>` (前缀是匹配设置里的别名)、`本月.存在` (右表是否匹配到, 布尔)、`基准日期`、变量定义里的名字
- 列名含 `-`、`/`、全角括号的直接写: `本期.类别-会议 == "变动通报"`、`非空(本期.岗动-拟任命人-流程节点)`。`-` 后面紧跟 `别名.`、数字或已知名字时才是减号 (`本期.金额-上期.金额`、`本期.金额-1`、`本期.金额-偏差率`), 不确定就加空格
- 列名含其它符号 (半角括号、空格、`%` 等) 的用反引号包裹整个名字: `` `本期.金额(万元)` > 100 ``。反引号里的名字必须在命名空间里, 否则报错
- 运算: `+ - * /`、`== != > >= < <=`、括号
- 字面量: 数字、`"字符串"` (必须加引号)、`是` / `否` / `true` / `false`
- 函数:

| 函数 | 含义 |
|---|---|
| `abs(x)` `round(x, n)` | Python 内置, 对整列逐行生效 |
| `min(...)` `max(...)` | Python 内置, 只适合标量参数 (如 `min(主表.金额, 100)` 这类对整列取小会报错) |
| `天数差(晚, 早)` / `days_between(晚, 早)` | 两个日期相差的天数 |
| `非空(x)` / `为空(x)` | 判空, 返回布尔 |
| `属于(x, 值1, 值2, ...)` | x 等于任一个值 |

**YAML 条件里的几条规矩** (因为是 Python 对整列运算):

- 多个条件用 `当:` 下多行 (AND) 或 `任一满足:` (OR), 不要写 `and` / `or` / `not`
- 区间写两行 `偏差率 >= 0.02` 与 `偏差率 <= 0.05`, 不要写链式比较
- "等于其中之一"用 `属于(主表.等级, "VIP", "金卡")`, 不要写 `in`
- 布尔列写 `本月.存在 == 是` / `== 否`
- 比较不自动忽略空值: `本月.电话 != 主表.电话` 在主表电话为空时为真, 需要时自己加一行 `非空(主表.电话)`

## 6. 规则文件: YAML 写法

```yaml
匹配:                                  # 同 Excel「匹配设置」, 键名相同
  左表: 客户主表.xlsx
  右表: 本月流水.xlsx
  左表别名: 主表                        # 可省, 默认 主表
  右表别名: 本月                        # 可省, 默认 本月
  匹配键: 客户编号
  右表重复键: 取第一条                  # 可省
  基准日期: 2026-10-19                  # 可省, 默认运行当天
  输出: output/客户主表_更新后.xlsx     # 可省, 默认 output/结果.xlsx

变量:                                  # 可省; 有序, 后面的可引用前面的
  偏差率: abs(本月.金额 - 主表.金额) / 主表.金额
  距上次活跃天数: 天数差(基准日期, 主表.上次活跃)

命中策略: 优先级                        # 可省, 默认 优先级; 或 唯一 / 首次命中

规则:
  - 编号: R1                           # 可省, 默认 R1、R2…
    名称: 活跃客户金额偏差超 5% 需复核    # 可省, 只作说明
    优先级: 1                          # 可省, 默认 1000 + 序号
    当:                                # 条件树, 见下; 省略 = 无条件命中
      - 主表.状态 == "活跃"
      - 本月.存在 == 是
      - 偏差率 > 0.05
    则:                                # 输出列 -> 值, 值的写法同 Excel 输出格; 省略 = 命中但什么都不改
      复核标记: 待复核
      备注: 金额偏差超 5%
      提醒: 清空                       # 把该列写成空值; 不想碰的列直接不写 (裸 - 在 YAML 里是语法错误, 要写 "-")

  - 编号: R5
    优先级: 5
    当:
      - 本月.存在 == 是
      - 任一满足:                      # OR
          - 为空(本月.电话)
          - 为空(主表.电话)
    则:
      提醒: 电话有缺失

测试:                                  # 可省
  - 用例: T1 偏差 8% 触发 R1            # 可省, 默认 T1、T2…
    输入: {主表.状态: 活跃, 偏差率: 0.08, 本月.存在: 是}
    期望: {复核标记: 待复核, 备注: 金额偏差超 5%}
  - 用例: T2 偏差 3% 不动
    输入: {主表.状态: 活跃, 偏差率: 0.03, 本月.存在: 是}
    期望: {}                           # 空 = 什么都不变
```

**条件树** (`当:` 的内容):

| 写法 | 含义 |
|---|---|
| 一个字符串 | 一条表达式 |
| 列表 | 全部满足 (AND) |
| `全部满足: [...]` | AND, 显式写法 |
| `任一满足: [...]` | OR |
| `不满足: <子条件>` | NOT |

三者可以互相嵌套。`当:` 省略或为空 = 无条件命中所有行。

**YAML 的两个坑**:

- 花括号流式写法里值含逗号必须加引号: `期望: {备注: "VIP 小幅偏差, 关注"}`, 否则逗号后面会被当成另一个键。块式写法 (每行一个键) 不需要。
- 表达式里的字符串要加引号: `主表.状态 == "活跃"`; 但 `则:` 和 `测试:` 里的值是普通 YAML 值, 不加引号。

一份能直接 `rule-sheet test` 通过的最小文件:

```yaml
匹配:
  左表: 客户主表.xlsx
  右表: 本月流水.xlsx
  匹配键: 客户编号

变量:
  偏差率: abs(本月.金额 - 主表.金额) / 主表.金额

规则:
  - 编号: R1
    当:
      - 本月.存在 == 是
      - 偏差率 > 0.05
    则:
      复核标记: 待复核

测试:
  - 用例: 偏差 8% 触发
    输入: {主表.金额: 10000, 本月.金额: 10800, 本月.存在: 是}
    期望: {复核标记: 待复核}
  - 用例: 本月缺失不触发
    输入: {主表.金额: 10000, 本月.存在: 否}
    期望: {}
```

## 7. 运行过程与输出

`run` 的顺序: 加载规则 → 跑内嵌测试 (有失败即停, 除非 `--ignore-tests`) → 读左右表 → 左表 left join 右表 → 求派生变量 → 逐条规则求命中 → 按命中策略合并 → 写出。

控制台会打印: 规则数与命中策略、每条测试用例的通过 / 失败及命中的规则、左表行数与匹配键、右表重复键提示、发生变更的行 (匹配键 + 命中规则 + 变更明细)、输出路径。

输出文件是**左表的副本**, 原表不动, 末尾多两列:

| 列 | 内容 |
|---|---|
| 命中规则 | 这一行命中了哪几条, 按优先级排, 如 `R1; R3`; 没命中为空 |
| 变更明细 | 每个被改的字段 `列: 旧值 -> 新值`, 多个用 `;` 分隔; 没变化为空 |

写出时自动设列宽、冻结首行首列、日期列格式 `yyyy-mm-dd`。目标文件被 Excel 打开而无法写入时, 自动改用 `_v2`、`_v3` … `_v9` 后缀, 都不行才报错。

**命中策略**:

- `优先级`: 多条规则同时命中一行时, **每个输出列**取优先级数字最小、且写了该列 (不是 `-`) 的那条。没有任何规则写该列则保持原值。
- `唯一`: 任何一行命中多条规则就报错停下, 错误信息里列出匹配键值与命中的规则 ID。
- `首次命中`: 每行只算优先级数字最小的那条命中, 其余规则对这一行视为未命中 (DMN 的 First)。该行的结果就是这一条规则的输出, 它没写的列保持原值; 一条没有任何输出的规则也能把一行拦下来, 不让后面的兜底规则改它。`命中规则` 列只记这一条。同优先级按书写顺序, 优先级留空取 `1000 + 行序`, 所以**建议每条都显式写优先级**, 否则挪动一行就会改变语义。

`优先级` 与 `首次命中` 的差别只在一行命中多条时: 前者逐列合并 (适合几条规则各管各的列), 后者整行听一条 (适合状态机: 先排除、再分类、最后兜底)。样例 `status-machine` 的 S2 在 `优先级` 下不占任何列, 会被兜底的 S4 改掉; 在 `首次命中` 下 S2 命中即停。

**数据类型**: 按 Excel 单元格类型走。设为文本格式的数字串 (电话、带前导零的编号) 按文本处理不会变数字; 数值列、日期列正常识别。两表的同名列在规则里靠别名前缀区分 (`主表.金额` / `本月.金额`); 匹配键列只保留左表的。

## 8. Python API

```python
from rule_sheet import run, run_tests, load_rules

res = run("examples/customer-sync/rules.yaml", dry_run=True)
print(res.changed[["客户编号", "命中规则", "变更明细"]])

outcomes = run_tests(load_rules("examples/customer-sync/rules.yaml"))
print([(o.name, o.passed, o.hit) for o in outcomes])
```

`run(rules_path, *, base_dir=None, ignore_tests=False, dry_run=False, output=None) -> RunResult`, 参数含义与命令行选项一一对应。

| `RunResult` 字段 | 内容 |
|---|---|
| `ruleset` | 加载后的 `RuleSet` |
| `tests` | 每条内嵌用例的 `TestOutcome` (`name` / `passed` / `hit` / `problems` / `error`); `tests_passed` 属性是通过数 |
| `stopped_by_tests` | 为 True 时因测试失败而停止, 以下字段为空 |
| `keys` | 匹配键列名列表 |
| `out` | 完整结果表 (左表副本 + 两列审计) |
| `changed` | `out` 中变更明细非空的行 |
| `written` | 实际写出的路径; `dry_run` 时为 None |
| `notes` | 运行提示, 如右表重复键按「取第一条」处理 |

## 9. 常见报错

| 现象 | 原因与处理 |
|---|---|
| `规则文件不存在: ...` | 路径写错 |
| `规则文件缺少「匹配设置」sheet` / `缺少「决策表」sheet` | sheet 名必须完全一致 |
| `匹配设置缺少「左表」` (或 右表 / 匹配键) | 这三项必填 |
| `匹配键「X」必须同时存在于左右两表` | 检查两表表头与匹配键拼写 |
| `右表有 N 行重复键, 而「右表重复键」设置为 ...` | 右表一对多; 设为 `取第一条` 或先去重 |
| `规则 R3: 规则引用了未定义的变量「...」` | 决策表第 3 行的变量名不在两表列名 (带别名前缀) 或变量定义里 |
| `表达式求值失败: '...' (...)` | 变量定义或 `=` 输出格的表达式有错, 括号里是 Python 原始错误 |
| `表达式求值失败: ... (「会议」既不是变量也不是可用函数; ...)` | 名字被拆开了: 表达式里写的名字 (如 `本期.类别-会议`) 不在两表列名里, 只匹配到前缀 `本期.类别`, 剩下 `会议` 落单。检查表头拼写; 含半角括号、空格等符号的名字用反引号包裹 |
| `表达式求值失败: ... (「float」既不是变量也不是可用函数; ...)` | 表达式只能用第 5 节列出的函数, Python 内置的 `float` / `str` / `int` 不开放 (它们对整列不是逐行生效)。要清空一列用输出格 `清空` |
| `表达式求值失败: ... (反引号里的变量「...」未定义)` | 反引号里的名字必须与表头 (带别名前缀) 完全一致 |
| `未知的命中策略「...」, 只认: 优先级 / 唯一 / 首次命中` | 决策表 B1 或 YAML `命中策略:` 拼写错 |
| `命中策略为「唯一」, 但以下行命中多条规则: {...}` | 规则重叠; 拆分条件或改用 `优先级` / `首次命中` |
| `无法识别的条件写法: ...` | YAML `当:` 里只认 表达式 / 全部满足 / 任一满足 / 不满足 |
| `有测试未通过, 停止处理真实数据` | 先修规则或用例; 确认无误可 `--ignore-tests` |
| `无法写入 ... 请关闭占用的 Excel 窗口` | 目标及 `_v2`..`_v9` 全被占用 |
| `错误: 2` | 左表或右表文件不存在 (目前只显示操作系统错误码), 检查匹配设置里的路径与 `--base-dir` |
